POSITION OVERVIEW
We are seeking a Senior Full-Stack Engineer to join our rapidly growing engineering team. 
The ideal candidate will have strong expertise in both backend and frontend development, 
with a proven track record of building scalable, high-performance applications. This role 
offers the opportunity to lead technical initiatives, mentor junior developers, and shape 
the future of our platform.

PRIMARY RESPONSIBILITIES
• Design and develop scalable backend services using modern web frameworks
• Build responsive and interactive user interfaces with modern frontend frameworks
• Architect and implement microservices-based systems
• Optimize database queries and application performance
• Implement security best practices and code reviews
• Mentor junior developers and lead technical discussions
• Collaborate with product team to understand requirements and constraints
• Deploy and monitor applications on cloud infrastructure
• Participate in on-call rotation for production support

REQUIRED TECHNICAL SKILLS

• CI/CD and DevOps experience with Jenkins, GitLab CI, or similar tools
• Cloud platform experience: AWS, Azure, or Google Cloud Platform
• RESTful API design and GraphQL (preferred)
